# 5 系统实现

本章节主要对系统的实现效果进行展示，结合前文的需求分析与详细设计结果，从普通用户、专业教练和管理员三类角色出发，对系统的主要功能模块进行说明。其中小程序端主要包括登录注册、健康数据记录、填写健康问卷、个性化减脂方案、在线咨询、积分兑换、社区互动、会员服务、教练服务评价和个人信息管理等功能；专业教练端主要包括登录注册、教练资质认证、查看用户数据、减脂方案优化、在线咨询回复、会员定制服务和查看服务评价等功能；后台管理端主要包括后台登录、审核教练资质、用户账号管理、社区内容审核和数据统计等功能。

### 5.1.3 填写健康问卷模块实现

填写健康问卷模块是本系统实现智能减脂服务的基础。用户在问卷页面填写年龄、身高、当前体重、目标体重、目标周期、饮食偏好和运动偏好等信息后，系统将结合用户的健康记录数据，计算基础代谢率和每日热量目标。该模块为后续个性化方案生成提供数据支持。
